# 2027 安达卢西亚页面模块

这是独立于仓库根目录西澳页面的本地行程模块，入口为 `andalusia-2027/index.html`。

## 本地预览

在仓库根目录启动静态文件服务器后访问：

`http://127.0.0.1:8766/andalusia-2027/`

## 内容维护

- `data.js`：每日行程、城市历史主题、预订/交通清单、阅读与来源。
- `styles.css`：响应式视觉样式。
- `app.js`：日期切换、清单状态与页面渲染。
- `index.html`：页面结构。

2027 年铁路时刻、票价和部分场馆节假日日历尚未最终公布；页面中保留了明确的待核状态与官方复核入口。
